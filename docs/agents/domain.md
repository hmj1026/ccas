# Domain Docs

This repository has one domain context. Before naming domain concepts or
changing business language, read [`GLOSSARY.md`](../../GLOSSARY.md). Use its
canonical terms rather than introducing synonyms.

Read relevant decisions in [`docs/adr/`](../adr/) before changing a recorded
trade-off. If a proposal contradicts an ADR, identify the conflict explicitly.

When terminology is genuinely unresolved, record the gap for domain modeling.
Create a new ADR only for a consequential decision with real alternatives;
ordinary file moves and implementation details do not need one.
